                      GET IT RUNNING

                      From zero to Claude writing on your canvas

                      This page already works in your browser. For Claude to read and write your diagrams, something has to run on your machine. Pick one:

                      You are already in the app. What is left is telling Claude where to find it.

                      1. 1 Download it
                        Windows macOS Linux

                        Rather run it from source with Python? The repo explains how.

                      2. 2 Open it

                        Windows: double-click it.

                        macOS: unzip it and move the app to Applications. It is not signed yet, so the first time macOS warns you: right-click it → Open, or System Settings → Privacy & Security → Open Anyway.

                        Linux: chmod +x DiagraMinder-linux && ./DiagraMinder-linux

                        It opens in its own window and tells you when there is a new version. Your projects live outside the program, so updating never touches them.

                      3. 3 Connect Claude Code

                        In the app: Settings → This program. Copy the .mcp.json it shows — address and password already filled in — and paste it at the root of your project.

                        In Claude Code, run /mcp: it should show diagraminder connected. Ask it to read your diagrams before it touches the code.

                      4. 4 Decide what it may do

                        Same screen, What the MCP can do: diagrams only (the default), diagrams + files inside one folder you pick, or also commands. The program enforces it, not the window.

                      5. 5 Claude web, too optional

                        Reach it from Claude web opens a Cloudflare tunnel (it needs cloudflared; the app tells you how to install it). Add the address it gives you as a custom connector in Claude web: it asks for the password once. The tunnel dies when you turn it off or close the app.

                      1. 1 Run the backend
                        Windows macOS Linux

                        Or from source, no dependencies: clone the repo and run python3 backend/server.py. The code is open: read it before you run it.

                      2. 2 Connect this page

                        Here: Settings → Connect backend. The first time it asks for a password: the backend prints it when it starts, and keeps it in token.txt inside its data folder.

                      3. 3 Use the chat

                        Open the chat and pick Local · Claude Code — or any agent CLI you already have installed. It runs on your own subscription, and it can read and edit the project you choose.

                      4. 4 Connect Claude Code

                        The backend's panel (http://127.0.0.1:8765/panel) shows the .mcp.json under MCP. Paste it at the root of your project and run /mcp in Claude Code. The same panel sets what the MCP may do.

                      5. 5 Claude web, too optional

                        From the same panel, the Cloudflare tunnel gives you an address to add as a custom connector in Claude web. It needs cloudflared and asks for the password once.
